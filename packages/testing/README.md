# @gable/testing

Test harness for Gable components: mounts into an in-memory renderer, no jsdom or browser needed.

## Install

```sh
npm install @gable/testing
```

## Documentation

See [docs/packages/testing.md](https://github.com/jcannon98188/gable/blob/main/docs/packages/testing.md) in the Gable repository.
