# @gable/ui

gable-ui: shadcn-style Tailwind components for Gable (buttons, forms, overlays, menus, navigation, data display).

## Install

```sh
npm install @gable/ui
```

## Documentation

See [docs/packages/ui.md](https://github.com/jcannon98188/gable/blob/main/docs/packages/ui.md) in the Gable repository.
