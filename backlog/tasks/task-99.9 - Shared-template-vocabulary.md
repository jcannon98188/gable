## Question

Which element tags, attributes, properties and events form the subset shared by the DOM renderer and Gable Native, and which are renderer-specific extras? Decide the native element set, how renderer-specific elements are typed for the template language service, how portable components are authored, and what unknown-tag errors say.

From the styling model grilling (not yet closed): the shared vocabulary must include the table tags (table, thead, tbody, tfoot, tr, th, td, caption, colgroup), which the native host lowers onto Taffy grid, and inline text elements (span, strong, em, a) as styled runs inside a block. Pseudo-elements (::before, ::after) are generated by the style system and add no tags.

Resolved with the user. Native uses HTML tag names with documented native semantics, no new primitive tags. v1 set: structure and text (div, span, section, article, nav, main, header, footer, aside, p, h1-h6, ul, ol, li, dl, dt, dd, blockquote, pre, code, a, strong, em, b, i, u, s, mark, small, sub, sup, br, hr, label, figure, figcaption); tables (table, thead, tbody, tfoot, tr, th, td, caption, colgroup, col, lowered onto Taffy grid per the styling model); controls (button; input types text, password, email, search, tel, url, number, checkbox, radio, range, hidden; textarea; select with option and optgroup; progress; meter; details with summary; dialog; form; fieldset with legend); media (img for PNG, JPEG, WebP, GIF and SVG sources with alt and object-fit; picture with source; video, audio, track and source; canvas with a 2D context mapped onto Skia); inline svg as a static subset parsed by usvg (svg, g, defs, use, path, rect, circle, ellipse, line, polyline, polygon, linearGradient, radialGradient, stop, clipPath, mask; viewBox, transforms, currentColor, CSS fill and stroke; text, filters, SMIL animation and foreignObject later). The user overrode my proposed deferral of video, audio, track, source and canvas: they are in v1 and the media and canvas implementation design (backends, frame path, canvas context) is split into research tickets (media playback; canvas 2D on Skia) and a grilling ticket. Not supported, with a clear dev-time error: iframe, object, embed, map, area, the document-level tags (html, head, body, title, meta, link, style, script, base, noscript), and template and slot (Gable has no template tag: components are small and composed, and slots belong to the template syntax, not elements). Picker input types (date, time, datetime-local, month, week, color, file) are deferred to Platform services and fall back to text with a diagnostic. Attributes and properties: one documented shared table per element (global id, class, style via setStyle, title, lang, dir, hidden, tabindex, role, aria-*, data-*; per element value, checked, disabled, readonly, required, placeholder, type, name, min, max, step, maxlength, href, target, src, alt, open, selected, rowspan, colspan, for, autofocus, plus the media attributes src, controls, autoplay, loop, muted, preload, poster, crossorigin, kind, srclang, label and default, and canvas width and height); unknown ones on a known element are a dev-time error; setProperty follows the primitives-only rule. The native host implements default behaviours: button, checkbox, radio and link activation (click, Enter, Space), label forwarding, form submit and reset on Enter or a submit button, details toggle, tab order, text selection and caret in text inputs, select popup; href click fires a click event first so the router can cancel it; external href handoff goes to the Platform services ticket. Typing: each renderer ships an element map (properties, tags, events) for the template language service, and a project's config names its renderer targets; with several targets templates are checked against the shared subset, and a tag or property outside it is a rule (default warn) naming the missing target; no conditional compilation in templates, platform variants are chosen through DI Tokens or entry points. No native-only tags in v1: the extension point is hyphenated names that a host registers, typed through the element map; an unregistered hyphenated tag is a native error. Unknown-tag errors name the renderer, give a did-you-mean, say whether the tag is known-but-unsupported or unknown, point to the vocabulary page, keep the meta.imports hint and stay dev-only. macOS: nothing here is platform-specific except media, which the media ticket covers.
